## ผลรวม

ยังไม่ผ่านทั้งความถูกต้องของปุ่มและความเหมือนต้นฉบับ หลายตัวมีโครงสร้างพื้นฐานของเอฟเฟกต์นั้น แต่มี mapping ผิด, ปุ่มไม่ถูกใช้, โมเดลซ้ำ และข้อผิดพลาดเชิง DSP

Core tests ผ่าน 49/49 (10,709 checks) แต่ authenticHardwareBrandFxModeling ตรวจเพียง stereo difference, bass boost, compression และค่าไม่เป็น NaN ไม่ได้เปรียบเทียบเครื่องต้นฉบับ ส่วน all61FxModels ตรวจการมีเสียงซึ่ง dry bypass ก็ผ่านได้

Probe เพิ่ม: sine 440 Hz amplitude 0.2, 2 seconds, normalized parameters ทุกตัว 0.5, wet=1, block=256 (ยกเว้นระบุ) ทั้ง 61 ตัวให้ค่าจำกัด ไม่ใช่การรับรองทุกค่าปุ่ม/sample rate หรือความปลอดภัยด้านระดับเสียง

## ข้อผิดพลาดสำคัญ

1. **P1 — Sound Maxer ไม่เข้า DSP ของตัวเอง**: metadata จัด PremiumUtilityAmp แต่ implementation อยู่ PremiumTubeEqDsp; utility ไม่มี branch รองรับ จึงปล่อย dry ผ่าน ผลต่างจาก dry ~7.1e-9 (ความคลาดเคลื่อนคำนวณ sine) ดู EffectsDsp.cpp:134, 1798, 2486.
2. **P1 — Delay ส่ง argument ผิดทุกเส้นทางใน slot**: implementation รับ timeL,timeR,feedback,crossMix,highDamp แต่ caller ส่ง time,feedback,ratio,hiCut,cross ส่งผลให้ feedback ไปเป็นเวลา R, feedback จริงเหลือระดับ 0.25–1%, hi-cut กลายเป็น cross-feedback เต็ม ไม่ได้กรองตามปุ่ม ดู :634, :2179–2235, :2287–2298.
3. **P1 — UI และ DSP ใช้ parameter contract คนละชุด**: FxFaceplateComponent.cpp:81 เขียน index โดยตรง แต่ X32FxRack.h:67–141 ตั้งชื่อต่างจาก mapping :2241–2546 เช่น Stereo Delay p1=MIX แต่ DSP เป็นเวลา; Xtec EQ1 p7=LO FREQ/p8=HI BW/p9=HI FREQ ไม่ถูกส่งเข้า EQ; Leisure p1=GAIN กลายเป็น Peak Reduction; Fair TIME กลายเป็น gain. ต้องทำ schema กลางรายรุ่น ไม่ใช่แก้แค่ข้อความ comment.
4. **P1 — หางเสียงถูกตัดตามจำนวน audio blocks**: :2105–2117 หยุดหลัง 120 บล็อกแม้ tail ยังอยู่ และ :2562 หยุดหลังช่วงเงียบก่อน delayed echo จะมาถึง ที่ block64 ตัดได้ราว 0.16s หรือเร็วกว่านั้น เทียบ block1024 ได้ max difference 0.00982158 จาก impulse เดียวกัน ต้องพิจารณาสถานะ delay/tail และเวลาจริง.
5. **P1 — Suboctaver หารความถี่เกินหนึ่งขั้น**: :1945–1987 นับ positive crossings สองครั้งแล้วจึง toggle ทำให้ OCT1 = f/4 และ OCT2 = f/8. Probe 200 Hz → OCT1 ได้ 50 Hz แทน 100 Hz; UI แสดง control B แต่ DSP ใช้ p4 เป็น range และไม่ได้ใช้ p5/p6.
6. **P2 — Reverb ไม่แยกบุคลิกตามชื่อ**: Hall/Ambience/Room/Chamber ใช้ comb+allpass เดียวกัน, Rich Plate/Plate เหมือนกัน, Vintage/Vintage Room เหมือนกันเมื่อค่าตรงกัน Probe Hall–Room และ Hall–Chamber ต่าง 0. BassMult เป็น output shelf ไม่ใช่ low-frequency decay multiplier; ATTACK p11 กลายเป็น spin และ SPIN p12 ไม่ถูกใช้. :378–610, :2269–2283.
7. **P2 — Modulation controls หลายตัวไม่มีผลหรือผิดหน้าที่**: Phaser BASE p4 เปลี่ยน 0→1 ผลต่าง 0, RESO ถูก map เป็น 200–2200 ก่อน clamp จึง feedback อิ่มตลอด; Mood BASE กลายเป็น mode และ MODE ไม่ถูกใช้; Rotary DISTANCE กลายเป็น fast switch, ไม่มี acceleration state; Dimension modes 2–4 ไม่ได้กำหนด mode จริง. :786–1030, :2301–2339.
8. **P2 — Limiter ไม่ใช้ attack/knee และ map release ผิด**: DSP :1623–1658 ไม่ใช้ p4/p5, UI ATTACK=p4/RELEASE=p5/KNEE=p6 แต่ mapper สลับ ความต่างเมื่อเปลี่ยน p5=0→1 เท่ากับ 0. ใช้ tanh และ gain จากสัญญาณปัจจุบันกับเสียงที่หน่วง ไม่ใช่หลักฐาน brickwall ceiling; ต้องทดสอบ transient overshoot เพิ่ม.
9. **P2 — Ultimo 20:1 ถูกตีความเป็น All-Buttons**: :1361 ใช้ p3>=20 ทั้งที่ mapper มีค่า 24 สำหรับ all-in; attack เพิ่มแล้วช้าลง, ratio เลื่อนต่อเนื่องแทนขั้น 4/8/12/20. Tests เดิมยืนยันพฤติกรรม 20=all-in ที่ผิดนี้ด้วย.
10. **P2 — Harmonic model ผิดความหมาย**: x*abs(x) เป็น odd-symmetric จึงไม่สร้าง even harmonics จาก sine สมมาตร แต่ถูกใช้เป็น even component ของ Tube Stage/Exciter; ไม่มี oversampling ใน nonlinear paths ที่ตรวจ จึงต้องตรวจ aliasing ก่อนอ้างความเหมือน analog.
11. **P2 — Dual หลายรุ่นไม่แยกค่าปุ่ม A/B**: :2137–2143 เปลี่ยน Dual ไป Stereo และใช้ค่าเดียวกัน แม้ state L/R แยกกัน ก็ไม่ได้เป็น independent controls; Combinator stereo/dual ใช้ detector อิสระเหมือนกัน.
12. **P2 — DeEsser ลบสัญญาณผิดแถบ**: :1571 เป็นต้นไปใช้ peaking EQ ที่ผ่านย่านนอก sibilance ด้วย แล้วลบทั้งสัญญาณนั้นจาก dry; low/high controls ถูกเฉลี่ยเป็น threshold เดียว จึงไม่ใช่การแยกสองย่านและ selective cancellation อย่างที่ชื่อสื่อ.
