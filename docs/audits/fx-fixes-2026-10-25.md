# FX corrections — 25 October 2026

## Implemented

- Sound Maxer reaches its DSP instead of dry pass-through; inline A/B controls are independent.
- Correct physical argument order for delay and combination processors. Stereo Delay UI MIX/TIME/factors/offset/filter controls reach the corresponding DSP values.
- Remove block-count silence shutdown; delayed first echoes and long reverb tails survive silence and are independent of host block size.
- Suboctaver divides by 2 and 4, not 4 and 8; inline A/B levels are independent.
- Distinct reverb geometry/diffusion/crossfeed for Hall, Ambience, Room, Chamber, plate and vintage-room families. Per-loop RT60 coefficients and bass-dependent feedback replace the output bass shelf. Fractional modulation avoids integer tap jumps. ATTACK and SPIN are separate controls. Reverse reverb uses rising reflection taps at normal playback speed instead of a double-speed buffer scan.
- Ultimo separates 20:1 from All-Buttons; discrete ratios and fast-clockwise attack. Ratio/all-in controls are exposed.
- Fair uses nominal six-position timing with detector-memory-dependent release in positions 5/6. This is an algorithmic approximation, not circuit identification. Timing reference: [UA Fairchild documentation](https://media.uaudio.com/support/downloads/UADManual_61.pdf).
- Limiter attack, knee and release are connected to the actual UI positions; linked safety gain guarantees the wet signal's sample ceiling. This is not an oversampled true-peak limiter.
- Two independently detected DeEsser bands subtract only extracted sibilance, preserving low-frequency material.
- Xtec EQ1 exposes high bandwidth/frequency/attenuation selector, low-frequency selector and output/transformer controls. Xtec EQ5 maps its actual boost/cut/frequency layout.
- Chorus/flanger use per-channel width/delay/phase; phaser base and resonance work; Mood base/resonance/mode map correctly; Dimension mode switches contribute to depth; Rotary has speed inertia and an exposed fast switch; Tremolo phase/wave/depth map correctly.
- Tube Stage EVEN produces an even-symmetric term; zero input with bias no longer produces a constant offset from incorrect tanh subtraction. Nonlinear polynomial contributions are bounded. Gain/cut/shelf controls have separate roles. Exciter MIX=0 is dry.
- Edison low/high spread and centre/balance differ from Stereo Imager pan/side-shelf processing; normalized Enhancer uses its tone/width controls instead of the Sound Maxer delay path.
- Dual EQ/compressor/enhancer/exciter/amp/tube models have independent B parameter storage and processor state. Project serialization, copy/paste and offline export retain the B bank.
- Explicit parameter encoding distinguishes new physical defaults from normalized UI values; old projects retain automatic format detection. The first UI edit converts the displayed defaults together, avoiding mixed physical/normalized fields.
- Changing algorithms clears previous DSP state. Wave Designer neutral settings preserve the input, including low-level onset. GEQ respects dry/wet.

- Endpoints 0 / 0.5 / 1 across all 61 models at 44.1 / 48 / 96 kHz: finite output for the exercised inputs. This is not an exhaustive perceptual or level-safety certification.
- Impulse timing/feedback, block-size-invariant tails, actual octave frequencies, sample ceiling, independent banks, Pultec/phaser/Mood control response, even harmonics, neutral transient shaping and algorithm reset have dedicated assertions.
- Same core suite passes AddressSanitizer + UndefinedBehaviorSanitizer.
- Console scene/state test: **4,590 parameters, zero failures**, with additional explicit assertions for parameter encoding and B-bank round-trip; existing export/recording tests also pass.
- macOS application target `MixPracticeStudioPro` builds successfully. Existing AudioEngine deprecated writer API warning remains unrelated.

## Limits and follow-up work

This change fixes the critical audit failures and a substantial set of control mappings; it does **not** claim that every advanced X32 faceplate control or hardware emulation is now complete. Remaining examples include per-tap gain/pan/pattern controls, separate stereo delay feedback shaping, some modulation envelope/wave/stage controls, reverb crossover/high-shelf details, Exciter ZERO FILL, and exact guitar preamp control semantics. Existing numeric readouts for some controls still use generic or legacy scales.

Reverb geometry, reverse reflections, optical/vari-mu memory, EQ curves, cabinet filtering and harmonic models remain designed approximations. No hardware A/B audio, measured impulse responses or calibrated distortion reference was supplied. Nonlinear alias suppression/oversampling, true-peak limiting, measured TruEQ compensation and source-specific pitch artifacts require further work before claiming brand fidelity.

Removing unsafe silence shutdown increases CPU use while tails continue. The independent B worker only allocates the dynamics/EQ/utility engines it uses. No app bundle in the project root was overwritten; use the new build in `build-mac/MixPracticeStudioPro_artefacts/Release/`.
